# Travlog — лендинг по макету из Figma

Проект нашего трека «Из Figma на сайт»: вёрстка по бесплатному макету [Responsive Travel Landing Page](https://www.figma.com/community/file/1533371523286432790/responsive-travel-landing-page-free-figma-template-desktop-tablet-mobile) от uixdesignacademy (лицензия CC BY 4.0) в трёх размерах: Desktop 1440, Tablet 1024, Mobile 430.

**Живая страница:** https://makschakof.github.io/travel-landing/

## Как переносил макет

- **Сетка макета → контейнер и колонки.** Desktop: 12 колонок, поля 128, промежуток 32. Tablet: 8 колонок, поля 64. Mobile: 4 колонки, поля 16. В CSS — `width: min(100% - 2 × поля, 1184px)`; на 1440 карточка направления 373px, ровно как в Figma.
- **Стили цветов → токены.** Primary `#5D50C6`, Secondary `#F85E9F`, Orange `#FF5722`, Yellow `#FACD49`, Dark `#191825` → базовые и смысловые переменные в `:root`.
- **Шрифты.** Circular Std в макете платный → заголовки на DM Sans (вес 600 ближе всего к Circular Medium), текст — Inter.
- **Auto Layout → Flexbox и Grid**, подход «сначала телефон». Брейкпоинты 600 / 720 / 768 / 1200: компьютерная раскладка включается с 1200, где она помещается; на 1024 — раскладка планшета, как во фрейме Tablet.
- **Картинки** вырезаны из экспорта фрейма в 2x и отданы через `srcset` (1x и 2x); у коллажей белый фон сливается с градиентом через `mix-blend-mode: multiply`.
- **Контраст.** Розовый (2.96:1), оранжевый (3.16:1) и серый (3.43:1) из макета для мелкого текста не проходят норму 4.5:1 — взяты затемнённые варианты. Это предложение дизайнеру.
- **Чего не было в макете:** открытое мобильное меню, состояния кнопок; добавлены ещё 2 карточки направлений и 2 отзыва, чтобы стрелки и точки по-настоящему листали.
- **Проверка:** сверка с тремя фреймами, ширины 320–1920 без горизонтальной прокрутки, Lighthouse — Performance 98, Accessibility / Best Practices / SEO 100.
